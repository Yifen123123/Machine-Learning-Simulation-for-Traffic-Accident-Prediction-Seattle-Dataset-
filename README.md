# 交通事故之機器學習模擬 - 西雅圖數據集

這個專案使用機器學習模型來預測交通事故的嚴重程度，並進行特徵選擇與性能評估。數據來自西雅圖的交通事故資料集。

## Python版本：Python 3.13.0

## 📊 數據來源

本專案所使用的數據來自 

（https://blog.csdn.net/weixin_46277779/article/details/130841592）


## 📚學習目的

1. **數據清理與處理**
   - **刪除無關特徵**：從數據集中移除不必要的欄位，如 `OBJECTID`、`INCKEY` 等。
   - **處理缺失值**：對於缺失值，使用最常見的值填補（例如：`ADDRTYPE`、`COLLISIONTYPE` 等）。
   - **時間特徵轉換**：將時間欄位（如 `INCDTTM` 和 `INCDATE`）轉換為日期格式，並從中提取出年份、月份和小時等特徵。
   - **分類變數處理**：將分類變數進行 One-Hot 編碼。

2. **特徵工程**
   - 轉換時間欄位，生成新的特徵（如 `year`、`month`、`hour`）。
   - 重命名與處理 `UNDERINFL` 欄位中的重複信息。

3. **資料集處理**
   - **平衡數據集**：對於標籤類別不均衡的情況（例如 `y=0` 顯著多於 `y=1`），使用適當方法進行平衡處理。
   - **數據分割**：將數據分為訓練集和測試集。

4. **模型訓練與評估**
   - 訓練了多個分類模型：邏輯回歸、K-近鄰、決策樹、隨機森林等。
   - 使用 K-Fold 交叉驗證進行模型評估。
   - 計算並顯示模型性能指標：精確度、召回率、F1 分數等。

5. **模型比較與結果展示**
   - 將不同模型的性能進行比較，並以條形圖顯示各個評估指標（準確度、精確度、召回率、F1 分數）。

6. **特徵重要性分析**
   - 使用隨機森林模型進行特徵重要性排序，並展示最重要的特徵。

## 🔧使用工具

1. **Python**：程式語言，用於數據處理與機器學習模型構建。
2. **Pandas**：用於數據清理與處理。
3. **Numpy**：用於數值運算。
4. **Matplotlib & Seaborn**：用於資料視覺化，繪製圖表（例如條形圖、散佈圖等）。
5. **Missingno**：用於可視化缺失值。
6. **Scikit-learn**：用於機器學習模型構建與評估，包括模型訓練（如邏輯回歸、隨機森林等），以及資料預處理（如標準化與 One-Hot 編碼）。
7. **SimpleImputer**：用於填補缺失值。
8. **KFold**：用於交叉驗證。

## ▶️流程

1. 讀取並清理數據，刪除不必要的欄位。
2. 處理缺失值與進行特徵工程。
3. 使用 `train_test_split` 將資料分為訓練集與測試集。
4. 訓練多個機器學習模型，包括邏輯回歸、K-近鄰、決策樹與隨機森林。
5. 計算模型的評估指標（準確度、精確度、召回率、F1 分數）。
6. 比較不同模型的性能，並展示結果。
7. 執行特徵重要性分析，顯示對預測結果影響最大的特徵。
